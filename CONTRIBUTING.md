# Contributing

Thanks for your interest! Please open an issue before large changes.

- Keep shell scripts POSIX-ish and executable (`chmod +x`).
- Avoid committing generated images or large binaries.
- For new build flavors, update the matrix in `.github/workflows/build.yml` and document in README.
- Follow conventional commits or clear messages: `build:`, `docs:`, `feat:`, `fix:`, etc.
- Run the workflow on a branch in your fork before opening a PR.
